# 🎲 D20 Tavern — เกมแนว D&D บนมือถือ

เว็บเกมเล่นผ่านเบราว์เซอร์มือถือ (ไม่ต้องลงแอป) สร้างห้อง ชวนเพื่อน แล้วผจญภัยด้วยลูกเต๋า 20 หน้า

## เล่นยังไง (Step by Step)

1. **DM** ใส่ชื่อ → เลือกรูปแบบเกม → กด **สร้างห้อง** → ได้รหัสห้อง 5 ตัว
2. DM กดที่ **"ห้อง XXXXX 📋"** ด้านบน เพื่อแชร์ลิงก์ให้เพื่อน
3. **ผู้เล่น** ใส่ชื่อ + รหัสห้อง → กด **เข้าร่วม** → ไปแท็บ 🧙 ตัวละคร ตั้งชื่อ/ค่าสถานะ
4. DM ไปแท็บ 👑 DM → **ตั้งฉาก** (สถานการณ์ที่ผู้เล่นเจอ)
5. ผู้เล่นไปแท็บ ⚔️ การกระทำ → **พิมพ์สิ่งที่อยากทำได้อิสระ** → ส่งให้ DM
6. DM เลือกได้ 3 แบบ:
   - 🎲 **ให้ทอย** — ตั้ง DC (ความยาก), ค่าสถานะ, ได้เปรียบ/เสียเปรียบ, โบนัส, ซ่อน DC ได้
   - ✅ **ทำได้เลย** — สำเร็จโดยไม่ต้องทอย
   - 🚫 **ทำไม่ได้** — พร้อมบอกเหตุผล/คำแนะนำ
7. ผู้เล่นกด **ทอย D20!** → ระบบทอยให้ (D20 + โบนัส ≥ DC = สำเร็จ, 20 เป๊ะ = สำเร็จขั้นสุด, 1 = พลาดขั้นสุด)
8. DM **เล่าผลลัพธ์** แล้วเล่นต่อ

## 🌍 โลก/ธีม

ตอนสร้างห้อง เลือกโลกได้จากการ์ดธีม:
- **🏴‍☠️ ทะเลพันเกาะ** — โลกโจรสลัดผจญภัย (เนื้อเรื่องต้นฉบับ): เกาะ 8 แห่ง, landmark 30+ จุด, ตัวละคร 25 ตัว (พันธมิตร/ตัวร้าย/ฝ่ายกลาง), 3 ฝ่าย, อีเวนต์ประจำเกาะ + อีเวนต์กลางทะเล, บทบาทลูกเรือ 8 แบบ, พลัง "หินพลังทะเล" 8 แบบ
- **✏️ กำหนดเอง** — ตั้งชื่อโลก เขียนตำนาน เป้าหมาย และมาตรวัดเอง หรือกด "🤖 ให้ AI เขียน"
- ธีมอื่น (มังกร / ไซเบอร์พังก์ / สยองขวัญ) — เร็วๆ นี้

แท็บ **🗺️ โลก**: ตำนาน · เป้าหมายแพ้/ชนะ · มาตรวัด (เศษแผนที่, การไล่ล่า, สภาพเรือ, ค่าหัว) · แผนที่เส้นทาง · ข้อมูลเกาะ · สมุดรายชื่อตัวละคร
- ผู้เล่นเห็นรายละเอียดเกาะ/ตัวละครเฉพาะที่ไปถึงแล้ว · **ความลับและตารางอีเวนต์เห็นแค่ DM**
- **ชนะ** เมื่อเป้าหมายชนะครบทุกข้อ · **แพ้** เมื่อมาตรวัดถึงจุดแพ้ หรือลูกเรือ HP 0 ทุกคน · DM ประกาศชนะ/แพ้เองได้
- AI DM รู้ทั้งตำนาน ความลับ และเป้าหมาย และอัปเดตมาตรวัด/เป้าหมายเองตามเรื่อง

## 🎨 แต่งตัวละคร & โปรไฟล์ DM

- แท็บ 🧙 ตัวละคร → **🎨 แต่งตัวละคร**: แต่งแบบ Pixel (สีผิว ทรงผม สีผม ตา ปาก ชุด สีชุด หมวก เครื่องประดับ พื้นหลัง + ปุ่มสุ่ม) หรือ **📷 อัปโหลดรูป** (ย่อเหลือ 128×128 อัตโนมัติ)
- **DM คนจริง**: แท็บ 👑 DM → โปรไฟล์ DM (รูป + ฉายา) — ขึ้นข้างทุกคำบรรยาย
- **AI DM**: เจ้าของห้อง → แท็บ ⚙️ ห้อง → โปรไฟล์ AI DM (รูป, ชื่อ, สไตล์การเล่า: ใจดี/ตลกกวนๆ/ดุดัน/ลึกลับน่ากลัว/ดราม่าอลังการ, บุคลิกเพิ่มเติม) — AI เล่าตามบุคลิกนี้จริง
- รูปขึ้นในเรื่องราว ปาร์ตี้ การกระทำ ตอนทอยเต๋า และแถบด้านบน · รูปจะหายไปพร้อมห้องถ้าเซิร์ฟเวอร์หลับ

## 🤖 ให้ AI (Gemini) เป็น DM — ฟรี

ตอนสร้างห้อง เลือก **"AI เป็น DM"** → ทุกคน (รวมเจ้าของห้อง) ได้เล่นเป็นผู้เล่น
AI จะ: สร้างฉาก · ตัดสินว่าทำได้ไหม/ต้องทอยไหม/DC เท่าไหร่ · เล่าผลหลังทอย (และลด/เพิ่ม HP) · ตอบคำถามในแท็บ "ถาม DM"
ลูกเต๋ายังทอยที่เซิร์ฟเวอร์เหมือนเดิม — AI เปลี่ยนผลทอยไม่ได้

**สลับได้ตลอด:** เจ้าของห้อง → แท็บ ⚙️ ห้อง → เลือกคนแล้วกด "ให้คนนี้เป็น DM" หรือกด "ให้ AI เป็น DM แทน"
ถ้า AI ตอบไม่ได้ (เช่น โควตาฟรีเต็ม) เกมจะแจ้งเตือน → กด "ลองใหม่" หรือสลับเป็นคนจริง

### วิธีเปิดใช้ AI (ทำครั้งเดียว)
1. เข้า **aistudio.google.com** ล็อกอินด้วยบัญชี Google → กด **Get API key** → **Create API key** → ก๊อป key
2. ไปที่ Render → เปิด Web Service ของเกม → เมนู **Environment** → **Add Environment Variable**
   - Key: `GEMINI_API_KEY`  Value: วาง key ที่ก๊อปมา → **Save**
3. รอ Render รีสตาร์ทเกม 1-2 นาที → ตอนสร้างห้องจะเลือก "AI เป็น DM" ได้

> ⚠️ ห้ามส่ง API key ให้คนอื่นหรือโพสต์ในที่สาธารณะ
> ตัวเลือกเสริม: `GEMINI_MODEL` (ค่าเริ่มต้น `gemini-flash-latest`) — ถ้า AI แจ้งว่า "ไม่พบโมเดล" ให้ใส่ชื่อโมเดลที่ AI Studio แสดง
> แผนฟรีมีโควตาจำกัดต่อนาที/ต่อวัน และเงื่อนไขเปลี่ยนได้ — เช็กที่ AI Studio

## ฟีเจอร์

| ส่วน | ทำอะไรได้ |
|---|---|
| 📖 เรื่องราว | ฉากปัจจุบัน, บันทึกทุกเหตุการณ์, แชทกลุ่ม |
| ⚔️ การกระทำ | ผู้เล่นประกาศการกระทำอิสระ / DM อนุมัติ-ปฏิเสธ-ตั้ง DC |
| 🧙 ตัวละคร | ชื่อ, อาชีพ, HP, ค่าสถานะ, กระเป๋า, บันทึก · DM ลด/เพิ่ม HP และเชิญออกได้ |
| 🎲 ทอยเต๋า | d4 d6 d8 d10 d12 d20 d100, หลายลูก, โบนัส, ได้เปรียบ/เสียเปรียบ · DM ทอยลับได้ |
| ❓ ถาม DM | ผู้เล่นถามสถานการณ์/กติกา (สาธารณะหรือส่วนตัว) DM ตอบ · ดูสรุปกติกาห้อง |
| 👑 DM | ตั้งฉาก, บรรยาย/ให้คำแนะนำ, ตั้งระบบเกม |

**ระบบเกมที่ DM เปลี่ยนได้ระหว่างเล่น**
- รูปแบบ: **D&D คลาสสิก** (STR DEX CON INT WIS CHA, โบนัส = (ค่า−10)÷2) · **D20 แบบง่าย** (ไม่มีค่าสถานะ) · **กำหนดเอง** (ตั้งชื่อค่าสถานะเองได้สูงสุด 8 ค่า)
- ธีมโลก: แฟนตาซี, ไซไฟ, สยองขวัญ, โลกปัจจุบัน, ไซเบอร์พังก์, อื่นๆ
- DC เริ่มต้น, เปิด/ปิด crit 20/1, ได้เปรียบ/เสียเปรียบ, ต้องอนุมัติทุกการกระทำหรือไม่, ผู้เล่นทอยอิสระได้ไหม, กติกาเพิ่มเติม (house rules)

**ความยุติธรรม:** ลูกเต๋าทุกลูกทอยที่เซิร์ฟเวอร์ (ใช้ crypto random) — ผู้เล่นโกงเลขไม่ได้ และผู้เล่นมองไม่เห็นการกระทำที่รออนุมัติของคนอื่น, DC ที่ซ่อน, ทอยลับของ DM, คำถามส่วนตัว

**หลุด/รีเฟรช:** กลับเข้าห้องเดิมได้อัตโนมัติ ตัวละครยังอยู่ (จำผ่านเบราว์เซอร์เครื่องเดิม)

## รันบนเครื่อง

ต้องมี Node.js 18 ขึ้นไป

```bash
cd dnd-game
npm install
npm start          # เปิด http://localhost:3000
npm test           # ทดสอบระบบทั้งหมดอัตโนมัติ
AI_MOCK=1 npm start   # ลองโหมด AI DM แบบจำลอง (ไม่ต้องมี key)
```

เล่นกับเพื่อนใน Wi-Fi เดียวกัน: ให้เพื่อนเปิด `http://<IP เครื่องคุณ>:3000` บนมือถือ

## เอาขึ้นออนไลน์ (ให้เพื่อนเล่นจากที่ไหนก็ได้)

ต้องใช้โฮสต์ที่รัน Node.js และรองรับ WebSocket (เช่น Render, Railway, Fly.io) — **GitHub Pages ใช้ไม่ได้** เพราะรันได้แค่ไฟล์หน้าเว็บ ไม่มีเซิร์ฟเวอร์

ตัวอย่างค่าที่ต้องตั้ง: Root directory = `dnd-game`, Build = `npm install`, Start = `npm start` (พอร์ตอ่านจาก `PORT` อัตโนมัติ)
